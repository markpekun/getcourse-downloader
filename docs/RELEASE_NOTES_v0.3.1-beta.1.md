# GetCourse Video Downloader 3.2.0-beta.1

> Beta-релиз будет опубликован GitHub Actions для тега `v0.3.1-beta.1`.

## Основание сравнения

- Последняя опубликованная версия: `v0.3.1` (`d516fa6`, 2026-08-20).
- Последний коммит перед текущей HLS-доработкой: `7aab848`.
- Базовый коммит текущей ветки: `c27a85a`.

## Новое

- Уроки и курсы с поддерживаемой кастомной разметкой обнаруживаются надёжнее.
- Для каждой неудачной загрузки доступен диагностический отчёт с причиной и
  техническим кодом без личных параметров URL.
- HLS-загрузки возобновляются после временного сбоя, выбирают качество и собирают
  MP4 через быстрый concat-путь с резервным вариантом.
- Программа передаёт прогресс, авторизацию, отмену и итог через отдельный worker,
  поэтому интерфейс не блокируется долгой загрузкой.
- Добавлена автономная проверка среды `--self-test` для Firefox, FFmpeg и FFprobe.
- Добавлена расшифровка MPEG-TS HLS SAMPLE-AES для AAC и H.264, если ключ приходит
  по HTTPS через `KEYFORMAT=identity`.

## Исправлено после `7aab848`

- Временные ссылки на разные видео больше не объединяются только потому, что их путь
  совпадает; секретные подписи при этом не попадают в постоянный идентификатор.
- Одноимённые уроки сохраняются под стабильными разными именами вне зависимости от
  того, были ли они выбраны вместе или по одному.
- Плейлисты с сегментами `EXT-X-MAP` или `EXT-X-BYTERANGE` больше не создают заведомо
  некорректный MP4: пользователь получает объяснение неподдерживаемого формата.
- Worker не теряет отмену на старте и не пропускает события, которые были записаны
  несколькими частями. Отмена завершает зависший FFmpeg и дочерние процессы.
- Обычный адрес школы со словом `login` больше не вызывает ложное окно авторизации;
  CSS со словом `background` не скрывает модуль курса.
- Повреждённые локальные JSON-файлы и неполная запись настроек не должны мешать
  открыть приложение. В отчёты не попадают query-параметры и `user:password@`.
- `SAMPLE-AES` с clear key больше не останавливается до скачивания сегментов:
  расшифровка выполняется до передачи данных FFmpeg.

## Что проверить перед публикацией

1. Выполнить `.\build.ps1` на чистой Windows-машине.
2. Запустить собранный `GetCourseVideoDownloader.exe --self-test --report self-test.json`.
3. Проверить вход, выбор урока и загрузку разрешённого тестового видео в чистом
   профиле Firefox.
4. Сверить SHA-256 ZIP, SBOM и содержимое архива.
5. Только после успешных шагов опубликовать тег `v0.3.1-beta.1`; GitHub Actions
   создаст prerelease с ZIP, SHA-256 и SBOM.

## Ограничения

DRM не поддерживается и не обходится. SAMPLE-AES поддерживается только для
MPEG-TS H.264/AAC с `KEYFORMAT=identity` и HTTPS-ключом. Результаты автоматических
тестов не доказывают работу с каждой школой GetCourse или с конкретным защищённым CDN.

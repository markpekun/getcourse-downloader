# GetCourse Video Downloader 0.5.0

Обновлённый интерфейс и исправления загрузки уроков.

## Главное

- Единая тёмная тема с более понятным разделением курсов, подкурсов, модулей и уроков.
- Ровные отступы, ветки дерева, мягкая подсветка при наведении и круговой отклик на нажатие.
- Плавное раскрытие папок, смена статусов и автопрокрутка во время загрузки.
- Читаемое непрозрачное меню качества видео.

## Исправления

- Исправлено зависание при закрытии приложения.
- Исправлена пустая область уроков при повторном запуске загрузки.
- Улучшена обработка недоступных уроков и вложенных курсов с HTTP 403, вход и отображение подробностей ошибок.
- Выбор уроков, счётчики и состояние папок сохраняются при сворачивании и раскрытии.

## Скачать

Для Windows x64 скачайте **GetCourseVideoDownloader-win-x64.zip**, распакуйте архив целиком и запустите **GetCourseVideoDownloader.exe**. Рядом опубликованы SHA-256 архива и список зависимостей SBOM.

Начиная с этого выпуска версия записывается тремя числами без префикса: **0.5.0**.

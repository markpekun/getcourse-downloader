# GetCourse Video Downloader 4.0

Готовый архив для Windows 10/11 x64. Скачайте `GetCourseVideoDownloader-win-x64.zip`, полностью распакуйте его и запустите `GetCourseVideoDownloader.exe` из распакованной папки. Python, Firefox и FFmpeg устанавливать отдельно не требуется.

## Что нового

- Поддержаны доступные пользователю Kinescope HLS-плейлисты с `SAMPLE-AES`, `KEYFORMAT=identity`, фрагментированным MP4 и `EXT-X-BYTERANGE`.
- Если звук указан отдельной дорожкой в master-плейлисте, программа загружает её и объединяет с видео в один MP4.
- Исправлена обработка бинарного 16-байтного ключа и пустых `saiz`-блоков аудиофрагментов, которые мешали FFmpeg прочитать дорожку.
- При сбое звука уже полученное видео сохраняется как `*.video-only.mp4`, но загрузка не помечается завершённой.
- Улучшены имена файлов, стартовый экран и воспроизводимость Windows-сборки. Исправлена Linux-проверка типов в GitHub Actions.

Пользователь подтвердил успешное воспроизведение видео со звуком на одном доступном уроке. Это не означает совместимость с каждым курсом или видеохостингом. DRM и форматы ключей, отличные от поддержанного `identity`, не обходятся.

## Проверка архива

После загрузки можно сверить SHA-256 архива с файлом `GetCourseVideoDownloader-win-x64.zip.sha256`. В релиз также включён список зависимостей `sbom.cdx.json`.

Полный список изменений — в [CHANGELOG.md](https://github.com/markpekun/getcourse-downloader/blob/v4.0/CHANGELOG.md).

## Что нового

- **Удаление из списка курсов.** Теперь можно убрать сохранённый урок, модуль или курс. При удалении модуля или курса из списка также убираются вложенные уроки и разделы. Скачанные видео остаются на диске.
- **Поиск и удаление дубликатов видео.** Приложение находит точные копии в папке загрузок. Можно выбрать лишние файлы для удаления. В каждой группе сохраняется одна копия.
- **Поддержка нового формата курсов GetCourse.** Приложение находит уроки, ссылки на которые скрыты за изображениями на странице курса.

Скачайте **GetCourseVideoDownloader-win-x64.zip** из раздела **Assets** ниже, распакуйте архив целиком и запустите **GetCourseVideoDownloader.exe**.

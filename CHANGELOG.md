## [3.2.0-beta.1] — 2026-09-16

Beta-релиз. GitHub Actions создаёт prerelease после публикации тега
`v0.3.1-beta.1`.

### Добавлено

- Диагностические отчёты по отдельным урокам и кнопка «Подробнее» в списке загрузок.
- Поддержка ряда кастомных страниц GetCourse и классификация ошибок доступа.
- Пассивный сбор HLS-плейлистов с сохранением заголовков запроса; приложение не
  нажимает плеер и не запускает видео.
- Возобновление HLS-загрузок, выбор качества и сборка MP4 сначала в временный файл.
- Worker с типизированными JSONL-событиями, отчётом об остановленной загрузке и
  остановкой дочернего дерева процессов.
- Офлайн-проверка исходной среды `--self-test`: отдельный Firefox-профиль, тестовый
  MP4 и проверка FFprobe без курса и без авторизации.
- Расшифровка HLS SAMPLE-AES для MPEG-TS с AAC и H.264, если ключ передаётся по
  HTTPS через `KEYFORMAT=identity`. Ключ не записывается на диск.

### Исправлено

- Идентичные названия уроков больше не перезаписывают и не ошибочно пропускают друг
  друга при загрузке по отдельности.
- HLS-плейлисты с разными значимыми query-параметрами больше не смешиваются; URL с
  обновляющимися подписями продолжают возобновлять загрузку.
- Варианты HLS без `RESOLUTION` выбираются по `BANDWIDTH`; `EXT-X-MAP` и
  `EXT-X-BYTERANGE` завершаются понятной ошибкой вместо повреждённого MP4.
- Отмена останавливает FFmpeg и worker даже во время запуска; разделённые записи
  JSONL и разделённые UTF-8 символы корректно дочитываются.
- Нестандартные страницы не ошибочно принимаются за login из-за слов `login`, `back`
  или `background` в имени школы и CSS.
- Запуск из исходного кода использует Firefox, установленный Playwright; отменённый
  запуск освобождает блокировку браузерного профиля.
- Повреждённые JSON-кэши не ломают запуск, а диагностика не сохраняет параметры URL
  и данные входа.
- `SAMPLE-AES` с clear key больше не ошибочно завершается кодом
  `ENCRYPTED_PLAYLIST_UNSUPPORTED`; сегменты расшифровываются до FFmpeg.

### Изменено

- В строке состояния урока во время передачи отображается короткое «Загрузка».
  Детали ошибок остаются доступны в отчёте урока.

### Ограничения проверки

- Тесты используют синтетические HLS, worker и браузерный профиль. Реальная
  авторизация, конкретная школа и защищённый CDN не проверялись.
- DRM не поддерживается и не обходится.
